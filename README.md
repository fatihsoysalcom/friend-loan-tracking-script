# Friend Loan Tracking Script

This Python script demonstrates how to track money lent to friends. It uses a simple JSON file for persistence, allowing users to record loans and repayments. The script calculates outstanding balances for each friend, illustrating a practical approach to managing informal debts and preventing forgetfulness.

## Language

`python`

## How to Run

1. Save the code as `loan_tracker.py`.
2. Run from your terminal: `python loan_tracker.py`
